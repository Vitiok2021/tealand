
# Tealand

## Опис
Магазин чаю з інтерактивною галереєю та картами продуктів. Простий та елегантний дизайн, що фокусується на продуктах.

## Технології
- HTML5
- SCSS
- JavaScript
- Адаптивна верстка
- Фільтри для швидкого пошуку продуктів
